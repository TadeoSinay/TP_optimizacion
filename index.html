📄 Consigna — Planificación Agregada de la Producción

🟫 Investigación Operativa I4051 🔵 MILP · Aggregate Planning Horizonte 12 meses

Partiendo de datos iniciales, se pide realizar la planificación agregada de la empresa con un horizonte de un año y períodos mensuales. El objetivo es hallar el plan de costo total mínimo que satisfaga la demanda, decidiendo mes a mes la cantidad de operarios (contrataciones/desvinculaciones), los turnos, las horas extra, la tercerización y el inventario.

Cada grupo debe armar su esquema y luego darlo a conocer al resto de los equipos, explicando las decisiones tomadas. La consigna completa (con la formulación matemática y la guía de implementación en PuLP) está en CONSIGNA.md.

Datos principales:

Cada operario puede producir 20 piezas por hora. Se trabaja 20 días al mes con uno o dos turnos de 6 horas cada uno (120 horas por turno-mes). Cada hora normal cuesta $100 y cada hora extra $120, con un máximo de 32 horas extra por operario y por turno.

Restricciones: mínimo 8 operarios, máximo 18, operarios año anterior 10, inventario inicial 8.000 unidades y capacidad máxima 45.000 unidades.

Costos: contratar $25.000, desvincular $50.000, producir $20 por unidad, almacenar $7 por unidad y tercerizar $100 por unidad.

🧮 Modelo matemático (MILP)

Formulación del problema — es el enunciado, no la solución. Se pide comprenderla e implementarla.

Variables de decisión (mes t = 1..12)

VariableDescripciónDominio
W_toperarios activos en el mesentero, 8 ≤ W_t ≤ 18
H_toperarios contratadosentero ≥ 0
F_toperarios desvinculadosentero ≥ 0
s_tturnos activosentero, s_t ∈ {1, 2}
O_thoras extra totalescontinuo ≥ 0
T_tunidades tercerizadascontinuo ≥ 0
I_tinventario al cierre del mescontinuo ≥ 0
P_tproducción propia (auxiliar)continuo ≥ 0

Función objetivo — minimizar el costo total anual

min Z = Σ_t ( 20·P_t # producción + 100·(120·W_t·s_t) # mano de obra normal + 120·O_t # horas extra + 100·T_t # tercerización + 7·I_t # almacenamiento + 25000·H_t # contratación + 50000·F_t ) # desvinculación

Sujeto a

(R1) W_t = W_{t-1} + H_t - F_t # balance de personal, W_0 = 10 (R2) 8 ≤ W_t ≤ 18 # límites de plantilla (R3) s_t ∈ {1, 2} # turnos discretos (R4) O_t ≤ 32·W_t·s_t # tope de horas extra (R5) P_t = 20·(120·W_t·s_t + O_t) # producción propia (R6) I_t = I_{t-1} + P_t + T_t - D_t # balance de inventario, I_0 = 8000 (R7) 0 ≤ I_t ≤ 45000 # capacidad de almacenamiento (R8) I_t ≥ 0 # demanda cubierta, sin faltantes (R9) W_t,H_t,F_t ∈ Z⁺ ; O_t,T_t,I_t,P_t ≥ 0
💡 Nota de modelado: los términos W_t·s_t (R4, R5 y FO) son bilineales. Para resolverlo como MILP puro se puede linealizar con una binaria de "segundo turno" (big-M) o redefinir la unidad como "operario-turno" acotada por 8 ≤ Ŵ_t ≤ 36. Justificar la elección en el informe.
